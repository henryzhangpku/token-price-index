Token price index · reference implementation

Anyone can average prices. A benchmark decides which goods have one.

A daily index over LLM inference pricing, built to the standard a cash-settled contract would demand: reproducible years later, defensible to a counterparty who lost money on it, and honest about the goods it cannot measure at all.

1 · the question

What is being measured

What did a million tokens of this model cost, from anyone who would sell them, today? Not what a buyer negotiated, and not what the market spent in aggregate — the price of one good, from the sellers offering that same good.

2 · the central decision

Which goods can carry an index, and which cannot

A benchmark measures price discovery, and discovery requires more than one seller of an identical good. Open-weight models qualify: the same weights are served by many independent providers competing on price. Proprietary frontier models do not, because each has exactly one.

This is a property of the good, not of the data, so it is checked before anything is collected. TIX-FRONTIER-OUT is refused by a gate rather than by a shortage of inputs.

4 · restatement

Everything is expressed as the standard contract, or discarded

servingfactorwhy
standard1.00the benchmark good
batch2.00published at 50% off by every major seller
cached10.00cache reads run near a tenth of standard input
priority0.50published at 2× by at least one seller

Two of these are close to observable, which is unusual for an adjustment schedule. Anthropic publishes batch at 50% and cache reads at roughly a tenth of standard input; OpenAI publishes the same two ratios. A ratio published identically by two independent sellers is a market convention. A ratio applied identically across every SKU of one seller is that seller's discount policy and carries no information.

Cumulative adjustment is capped at 5.0×, which binds on the cache factor. Restating a cache read to standard multiplies by ten, so nine tenths of the resulting number would come from this schedule rather than from the seller. That is not an observation about standard pricing; it is the schedule talking, and it is discarded. Batch at 2× survives, because half the number is still the seller's.

An earlier draft set that ceiling at 10.5×, which no combination of factors could reach — serving is a single enum and the context factor only reduces. A ceiling nothing can touch is not a control. A test caught it.

5 · estimation

What the estimator does, and why

One good per index

Input and output never blend. They are priced differently by every seller and consumed in different ratios, so any blend depends on a ratio nobody can observe.

One seller, one vote

Each provider collapses to a single median first. Serving forty models buys no more influence than serving one.

Screen robustly

Median absolute deviation × 1.4826, which has a 50% breakdown point — not standard deviation, which has none, because the outlier inflates the very yardstick measuring it.

Where MAD goes to zero

If every honest seller agrees exactly there is no scale left, so the screen falls back to a symmetric ratio band. A percentage test caps at 100% on the downside and could never catch a near-zero price.

A stated precision

Published to four decimal places, summed in a fixed order. Floating-point addition is not associative, so an unrounded mean can differ in its last bit between two runs over the same market. A property test found it.

Withholding is an outcome

A gap in a series is a fact about the market. An interpolated value is a fiction about it.

Two of the five gates are doing nothing today, and one is doing everything. That is worth stating rather than hiding: the only reason this index prints at all is a provider floor of three, and three is roughly the maximum this market currently offers. The index is waiting for the market, not the other way round.

7 · stated plainly

What this cannot do

A methodology that only lists strengths is a marketing document.

One collection date

Prices were read once. There is no time series, so no chart is drawn — re-running a fixed table daily would manufacture a flat line that looks like data and is not.

No transaction data

Every input is a published rate card. Nobody here observes what anyone paid, and enterprise inference is negotiated and invisible. This measures the retail tail.

No quality adjustment, and this is the deep one

Price per token falls while capability rises. A token is treated as a token, so a falling series cannot distinguish cheaper inference from better models. That is the hedonic problem official statisticians solve for computer prices — and here it may be the dominant term.

Model identity is assumed

Two sellers listing the same model may serve different quantisations, context limits or throughput. The contract pins the weights; it does not pin what you actually get.

No source adapters

One dated, sourced table read by hand. The collection architecture is real; the collection is not yet.

Thresholds are judgement

Unlike the compute benchmark's contributor-shift check — measured from 403 observations — nothing here is calibrated, because one collection date supports no calibration. The checks exist and report not_evaluable rather than passing quietly.
