the finding

A frontier index is one seller’s list price wearing an index’s name

A benchmark measures price discovery. Only Anthropic sells Opus 5. Only OpenAI sells GPT-6 Astra. There is no second price for the same good, so there is nothing to discover, no dispersion to measure, and no sense in which an average of them is a market rate.

Averaging across different frontier models is worse. It silently assumes those models are substitutes — which is precisely the assumption a buyer is paying not to have to make.

So TIX-FRONTIER-OUT exists in this repository to be refused. Its contract is deliberately ill-defined, because that fiction is the point: try to write the contract down and you find there is no single good to write.

the other half

Open weights are a real market, and the spread proves it

The same weights are served by many independent providers competing on price. That is where discovery actually happens, and it is the only place an index over inference means anything.

method

What the estimator does, and why

One good per index

Input and output never blend. They are priced differently by every seller and consumed in different ratios, so any blend depends on a ratio nobody can observe.

Rank inputs by what they prove

A published token price is transactable today by anyone with a card — so unlike compute rental, the top evidence tier is genuinely populated.

One seller, one vote

Each provider collapses to a single median. Serving forty models buys no more influence than serving one.

Screen robustly

Median absolute deviation, which has a 50% breakdown point, not standard deviation, which has none — the outlier inflates the yardstick measuring it.

Where MAD goes to zero

If every honest seller agrees exactly there is no scale left, so the screen falls back to a symmetric ratio band. A percentage test caps at 100% on the downside and could never catch a near-zero price.

Withholding is an outcome

A gap in a series is a fact about the market. An interpolated value is a fiction about it.

stated plainly

What this cannot do

A methodology that only lists strengths is a marketing document. The full list runs to seven; these are the three that matter most.

No transaction data

Every input is a published rate card. Nobody here observes what anyone paid, and enterprise inference — where the volume is — is negotiated and invisible. This measures the retail tail.

No quality adjustment, and this is the deep one

Price per token falls while capability rises. A token is treated as a token, so a falling series cannot distinguish cheaper inference from better models. That is the hedonic adjustment problem official statisticians solve for computer prices — and for a good improving this fast it may be the dominant term.

Model identity is assumed, not verified

Two sellers listing the same model may serve different quantisations, context limits or throughput. The contract pins the weights; it does not pin what you actually get.
